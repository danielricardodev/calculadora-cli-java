# 🧮 Calculadora CLI em Java

Este é um projeto simples de **calculadora que roda no terminal** (CLI - Command Line Interface), desenvolvido em Java. A calculadora permite realizar as quatro operações básicas: adição, subtração, multiplicação e divisão.

---

## 🚀 Funcionalidades

- ✅ Soma (`+`)
- ✅ Subtração (`-`)
- ✅ Multiplicação (`*`)
- ✅ Divisão (`/`)
- ⚠️ Verificação de divisão por zero
- 🔁 Loop para realizar múltiplas operações até o usuário digitar "sair"
